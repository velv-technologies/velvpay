# VelvPay Agent Instructions

## Owner approval for environment variables

Do not introduce a new environment variable name anywhere in the VelvPay codebase, including application code, `.env` files or examples, configuration, scripts, workflows, deployment instructions, or documentation, without the owner's express prior approval for that specific variable. Before asking, state its exact name, purpose, where it will be set and read, whether it is required, and its deployment impact. General approval to implement, merge, or deploy does not approve a new environment variable. Prefer existing configuration when it fully meets the need; record any approved new variable and the owner's decision in the task artifact.
